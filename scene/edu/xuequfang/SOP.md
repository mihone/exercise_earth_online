# 上海学区房调查 SOP

## 0. 定位

**这份 SOP 不是 `edu-result.md` 第八节的续写，是换框架。**

`edu-result.md` 的任务是**跨城成本对照**——学区房在那里只需回答「这笔钱多大、换到什么」，所以它是成本框架。本 SOP 的任务是**买入决策**，判据完全不同，第八节的内容只作为线索，不作为起点。

第一步已定的输入，直接继承，**不重新论证**：

| 输入 | 值 | 出处 |
|---|---|---|
| 目标口径 | 华理保底、同济上探、复交运气项；竞赛作添头 | `edu-result.md:9` |
| 初中档位 | **偏强但非顶级**（下限 211 + 上探 985 的对应解） | `edu-result.md:441` |
| 无条件禁令 | 避开「名额少的小强校」 | `edu-result.md:510` |
| 户籍/房产现状 | 已有沪籍、无上海房产 | 用户 2026-09 确认 |
| 孩子出生 | 计划 2029–2030 | 用户 2026-09 确认 |

## 1. 时间轴：一切剪枝的依据

按 2029/2030 年出生（8 月 31 日前）、上海五四制推算：

| 节点 | 2029 年出生 | 2030 年出生 | 距今 |
|---|---|---|---|
| 小学入学 | 2035.9 | 2036.9 | **9–10 年** |
| 初中入学（名额分配在此生效） | 2040.9 | 2041.9 | **14–15 年** |
| 中考 | 2044.6 | 2045.6 | **18–19 年** |
| 高考 | 2047.6 | 2048.6 | 21–22 年 |
| **买房 + 迁户口截止** | **2031.9 前** | **2032.9 前** | **5–6 年** |

买房截止的算法：热门校要求户口落在该址满 3–4 年 `[自媒体，待核实]`，故须在小学入学前 4 年完成过户 + 迁户。留出交易周期，**实际窗口 2030–2032**。

**两条由时间轴直接推出的结论：**

1. **早买对「五年一户」更安全。** 学位占用是按地址回溯查的。2030 年买入、2035–2036 年入学，前业主的使用记录自然落在 5 年窗口外；越晚买，前业主近期占用的概率越高。
2. **限购放开不解决入学资格。** 「能买」和「能入学」是两套规则；年限算的是户口在该房产地址的年数，已有沪籍不自动满足。限购放开只进入资产层（潜在买家池变大）。

## 2. 三层判据

学区房是三个**互相独立**的判断的交集，任一不过关即出局。上一份文档把三层混在一节里，所以每层都不完整。

### A 资格制度层 — 错了出局，不可补救

- 户籍年限要求（户口迁入该址满几年）
- 五年一户：本区是否执行、口径、是否含居住证积分占用
- 人户一致的认定
- **对口机制类型**（本层最该先分类的东西）

对口机制是被上一份文档埋掉的关键分岔：

| 机制 | 含义 | 对决策的影响 |
|---|---|---|
| **学籍对口** | 小学学籍直接决定初中 | **一次决策锁 14 年**，必须一次看穿两段 |
| **派位/摇号** | 小学与初中解耦 | 可两次决策，小学阶段仍能置换 |

证据：明珠 C 小学对口普通初中，大量家庭因此置换到建平地杰学区 `edu-result.md:504`。**这一项的优先级高于任何价格表。**

**来源要求：只认官方一手**（`shmeea.edu.cn`、区教育局、区政府文件）。拿不到就标红留空，**不许用二手填**。上一份文档这几条全是 `[自媒体]` 和政府网站转载（`edu-result.md:489-496`），而它们错一个就是几百万锁死。

### B 教育质量层 — 决定好坏，不决定生死

生效在 14–19 年后，**只查慢变量**（清单见 `reference.md`）。不查任何当期校级数据。

### C 资产层 — 上一份文档几乎空白

核心不对称：**教育价值窗口只有初中 4 年（2040–2045），资产暴露 15 年以上。**

退出时的买方是谁，第一步的数据已经算得出来，只是没被连过来：上海出生人口 2016 年 21.84 万 → 2023 年 9.8 万，**跌 55%**（`edu-result.md:528`）。2029–2030 年出生这批入学时，同龄人规模约为当前在读小学那批的一半。学区房溢价的基础是学位稀缺，生源腰斩后溢价基础同步松动。

不能断言溢价必跌（家长可能更集中挤头部、弱校先被撤并），但**「退出时面对生源腰斩后的买方」这个判断是硬的**，必须独立成层。

> 第九节的人口数据本来就在文档里，只被用来推高考门槛，没被用来推房价。**这就是「抓不到重点」的具体样子：数据有了，没连起来。**

C 层必查：挂牌价 vs 成交价（上一份价格表没区分）、溢价占比、户型可居住性、流动性。

## 3. 剪枝规则：按生效时点定查多细

**这是本 SOP 最核心的机制，也是上一份文档完全没有的概念。**

每个数据点先问「它在哪一年生效」，再定查多细：

| 距今 | 对应项 | 查到什么程度 |
|---|---|---|
| **5–6 年**（买房窗口） | 落户年限、五年一户、学位占用史、对口机制类型 | **查死**。官方一手 + 具体房源逐套核 |
| **9–10 年**（小学对口） | 小学对口关系 | 只查**机制类型**与**历史稳定性**（近 5 年调整过几次），不查具体名单 |
| **14–19 年**（初中对口、名额分配、中考） | 名额分配、区内高中格局 | **只查慢变量**。严禁精确到某校几个名额 |

### 一条必须撤回的建议

`edu-result.md:447-455` 把「该校到校名额数 / 是否倒挂 / 年级规模」列为「买房前必查的三个数」。**这条错了，本 SOP 撤回它。**

理由：那是 2026 年的数，要预测的是 2044–2045 年的中考。名额分配到校制度 2022 年才大改（此前以到区为主），2024 届民办纳入又改变一次分配格局（`edu-result.md:465`）。**用当期分校名额表推 15 年后，信息量接近零。**

### 慢变量 vs 快变量

| 慢变量（值得查） | 快变量（现在查了白查） |
|---|---|
| 区内市重点/区重点的**数量与地理分布** | 某校某年到校名额数 |
| 区的生源结构（民办占比高低） | 某校某年到校线是否倒挂 |
| 区级普高率的**长期档位**（静安 79% vs 金山垫底，`edu-result.md:62`） | 某年具体百分比 |
| 政策方向（名额分配比例在升不在降；大连同向推进到 80%，说明是全国方向 `edu-result.md:156`） | 当年具体比例 |
| 板块的城市规划、人口流入 | 当月挂牌价 |

**判据很机械：这个数查清了，会不会改变尽调表里某一格？不会就不查。**

## 4. 线上 / 线下边界

**前置声明，不放在结尾。** 上一份文档以「建议落定前直接找本区教育考试院核对」收尾（`edu-result.md:453`），等于把活儿推回给用户。

| 线上可得 | 必须线下 |
|---|---|
| 区级政策文件、对口机制类型 | 分校到校名额数（官方只公布测算口径） |
| 区级普高率、高中分布 | 特定房源的学位占用史 |
| 挂牌价 | 真实成交价、成交周期 |
| 政策方向 | 该校对口关系的稳定性体感 |

线下清单与话术见 `reference.md`。**但注意：按第 3 节的剪枝规则，14 年后才生效的项目现在不该跑线下**——线下动作留到 2030 年买房窗口开启时执行。**现阶段线下只做一件事：确认 A 层的资格条款口径。**

## 6. 执行流程

### Phase 0 — 冻结「现在不查」清单

**第一个动作不是检索，是划掉。** 按第 3 节列出所有 14 年后才生效的项目，明确标注「2038 年后再查」，本轮不碰。

这一步是防走形的第一道闸，必须产出物化清单。

### Phase 1 — A 层资格条款（本轮重点）

官方一手核实：落户年限口径、五年一户执行区、对口机制类型分类、人户一致认定。

按主人已确认的「从全市筛」，先做**全 16 区的对口机制分类表**（学籍对口 / 派位），这是粗筛的第一把刀——学籍对口区必须一次看穿两段，决策成本高得多。

### Phase 2 — 慢变量粗筛

用慢变量把 16 区筛到 3–5 个板块：区内重点高中分布、区级普高率档位、生源结构、规划人口。

叠加主人的约束（预算上限、通勤）。**此处需要补充输入。**

### Phase 3 — C 层资产筛查

对候选板块做：成交价（非挂牌价）、溢价占比拆解、户型可居住性、15 年退出情境下的流动性。

生源腰斩 55% 这个变量必须显式进入每个板块的判断。

### Phase 4 — 强制否证

对每条核心推论专门做一轮反例检索。

上一份文档最有用的段落是第八节「红利的三个失效条件」（倒挂、名额太少、够不到最低投档线，`edu-result.md:413-419`），而它恰恰来自反向检索——**把这个偶然做对的动作固化成必做步骤。**

### Phase 5 — 产出

```
scene/edu/xuequfang/
├─ SOP.md          # 本文件
├─ reference.md    # 字段定义、慢变量清单、线下话术、已知坑
├─ 候选池.md        # Phase 2 粗筛，每区一行，淘汰理由必写
├─ 尽调表.md        # Phase 1+3，每候选一张表
└─ 决策.md          # 一页：结论 + 未消除风险 + 框架外发现 + 2030 年待办
```

递进三文件，不写长文。`决策.md` 限一页。
